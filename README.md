# Expense Tracker

A responsive expense tracker built with HTML, CSS, and JavaScript. The app helps users record income and expenses, monitor their balance, and understand spending patterns with a clean dashboard.

## Live Project

After publishing with GitHub Pages, add your link here:

`https://abhishekv4321.github.io/expense-tracker/`

## Features

- Add income and expense transactions
- Track current balance, total income, and total expenses
- Filter transaction history by month
- View category-wise expense insights
- Delete unwanted transactions
- Save data using browser `localStorage`
- Responsive layout for desktop and mobile

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Local Storage API

## Folder Structure

- `index.html` - main page structure
- `style.css` - UI design and responsiveness
- `app.js` - app logic, filtering, and storage
- `.vscode/` - VS Code settings for easy local running

## How To Run Locally

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Run it with `Live Server` or open the file directly in your browser.

## How To Publish On GitHub Pages

1. Push this project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to `Settings > Pages`.
4. Under `Build and deployment`, select `Deploy from a branch`.
5. Choose branch `main` or `master`.
6. Choose folder `/ (root)`.
7. Save the settings.
8. GitHub will generate a live project link in a short time.
